## API semantics

All requests: **POST**, server-side only (no browser Origin), JSON, valid legacy JWT bearer or a signed-in verified operator JWT with server-controlled `app_metadata.atlas_operator=true`. Modern publishable API keys are not bearer JWTs.

`mode: "preview"` — validate and normalize one user/operator-observed social hypothesis; no database writes.

`mode: "persist"` — save source registry if new; append an unverified, discovery-only release, with a post-write readback. Dedupes sequential replays by fingerprint on a best-effort basis; absent a unique fingerprint index, this is **not atomic across concurrent callers**.

`mode: "list"` — read a bounded list (max 25) of existing saved releases; does not feed betting decisions.

Illustrative body (replace with a genuinely observed public post):
```json
{
  "mode": "preview",
  "source_url": "https://www.reddit.com/r/sportsbook/comments/REAL_POST_ID/example/",
  "handle": "r/sportsbook",
  "sport": "NBA",
  "claim": "Player opportunity may change with an announced rotation adjustment.",
  "event_label": "Actual matchup and event date",
  "market": "3PM OVER",
  "line": 2.5,
  "odds": -108,
  "released_at": "2026-10-21T11:15:00-05:00"
}
```
`released_at` is operator-asserted and UNVERIFIED; `captured_at` is generated by the server. Without `released_at`, the release time is stored as the observation time and explicitly labeled `OBSERVED_AT_ONLY`. Earlier publication cannot be inferred from a later capture.

Source allowlist: Reddit, X/Twitter, Instagram, YouTube on HTTPS. **Never fetches URLs**, preventing server-side request forgery and avoiding unapproved scraping. The operator's `original_url` is an unverified root-claim hint, not independent corroboration. Multiple reprints of one root do not become multiple verified facts.
